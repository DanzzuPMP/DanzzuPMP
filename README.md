## About

I work on Minecraft server software in PHP, mostly around protocols and cross-version compatibility. Right now I am building **Axiom**, a multi-version server where classic and modern clients play together in one world, with no extra proxy.

## Featured project

**[Axiom](https://axiommc.bond)** lets Bedrock `0.15.10` through `26.62` clients, and Java Edition `1.21.4` in preview, join the same server.

- Built-in translation, no external proxy
- Classic gameplay parity across versions
- Open for testers: see the website to apply
